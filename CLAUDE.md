# KASHTA project guidance

For product-flow, interface, or visual-design work, use the project skills `ui-ux-pro` and `taste-pro` before implementation. Use the UX skill for user journeys and interactions; use the Taste skill for art direction and visual critique. For substantial changes, use up to two subagents on independent, non-overlapping work when this will save time, and keep the main agent responsible for integration.

Preserve existing project work and follow `AGENTS.md`. Do not commit, push, or deploy unless the user explicitly asks.
